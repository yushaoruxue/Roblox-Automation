# Roblox 动漫远征 (AE) 自动刷图挂机助手使用指南

这是一个基于 **Python 外部模拟与计算机视觉 (OpenCV) 图像状态匹配** 开发的 Roblox 动漫远征 (AE) 辅助工具。该工具不注入游戏进程，并使用客户区相对坐标适配窗口大小。

> 重要：当前截图方式读取的是屏幕可见像素。Roblox 不能最小化，也不能被其他窗口遮挡。执行动作时程序会尝试把 Roblox 切到前台，并在每一步验证焦点、坐标和遮挡状态。

---

## 🛠️ 环境准备与安装

首先，您需要安装 Python（推荐使用 Python 3.10 或 3.11），然后在命令行或终端（PowerShell）中进入本项目目录并运行以下命令安装依赖：

```bash
pip install -r requirements.txt
```

---

## 🚀 核心功能与操作步骤

### 第一步：启动软件与选择窗口
1. 打开 Roblox 客户端并进入动漫远征的关卡（使游戏处于 **图一** 状态：屏幕上有“开始游戏”对话框，且横幅显示在屏幕中央）。
2. 推荐双击项目目录中的 `run.bat`，同意管理员权限提示后只保留主配置器窗口，启动命令行会自动隐藏。也可以在管理员控制台执行：
   ```bash
   python gui_app.py
   ```
3. 在软件界面的 **“目标游戏窗口”** 下拉菜单中，选择您的 Roblox 进程（例如：`Roblox (句柄: 123456)`）。如果找不到，可以再次展开下拉框来自动刷新。

---

### 第二步：截取识别特征图 (一次性配置)
为了让脚本自动判断“何时开局”，您需要手动截取游戏内的开始按钮图片：
1. 点击 **“截取 '开始游戏' 按钮”**：
   - 主界面会自动隐藏，屏幕颜色变暗。
   - 先拖动框选用于识别的稳定区域。可以包含按钮周围的固定对话框，但不要包含计时器、动态角色或变化文字。
   - 松开鼠标后，再单击绿色 **“开始游戏”** 按钮的中心作为实际点击锚点。
   - 程序会分别保存识别图和点击锚点；识别成功后点击锚点，不再盲目点击截图中心。
*注：这些小图片将保存在 `templates/` 目录中。只要您的游戏 UI 风格和按钮文案没有改变，后续再次运行软件无需重新截取。*

---

### 第三步：配置角色部署动作链
在右侧的动作列表中，配置您要部署的角色快捷键和它们放置的相对坐标：
1. **添加动作**：点击右上角的 **“+ 添加部署步骤”** 按钮。
2. **选择按键**：在下拉框中选择要按的数字键（例如选 `1`）。
3. **选取坐标**：点击 **“🎯 选取位置”** 按钮，主界面隐藏：
   - 在您的 Roblox 游戏战场内，直接用鼠标点击您想要摆放的位置。
   - 点击后，软件会自动保存该点相对于游戏窗口大小的百分比坐标。
4. **设置延迟**：在“放置后延迟(秒)”中输入适当的时间（例如 `0.5` 或 `1.0` 秒）。因为是幽灵模式放置，可以连续放置，但设置短延迟能保证游戏稳定响应不丢包。
5. **单步测试**：点击行尾的 **“测试”** 按钮，验证对应的按键与点击位置是否在游戏里正确触发。
   - “测试全部”可直接验证当前动作链，不会点击“开始游戏”，也不会进入挂机循环。
   - 整条动作链以及最终“开始游戏”点击期间，程序都会短暂锁定物理键盘和鼠标，防止打字、移动鼠标或滚轮操作干扰游戏；动作结束后立即释放。

### 部署方案与占位预览
部署步骤不会再在测试或启动挂机时隐式覆盖。修改后界面会显示“未保存”，由您明确决定何时保存。

1. **保存 / 另存为**：保存当前方案，或复制当前部署动作创建新方案。
2. **新建 / 重命名 / 删除**：多个地图或阵容可分别命名管理；删除的方案会移入 `profiles/.trash/`，不是立即永久删除。
3. **切换保护**：切换方案或关闭程序时，如有未保存修改，会询问保存、放弃或取消。
4. **截取预览**：部署角色后点击“截取预览”，程序会隐藏自身并保存所选 Roblox 客户区的完整画面；“查看预览”会按查看窗口大小等比缩放，便于确认角色占位。
5. **数据位置**：方案索引位于 `profiles/index.json`，每个方案使用独立 UUID 文件夹保存 `profile.json` 和可选的 `preview.jpg`。写入采用临时文件替换并保留 `.bak` 备份。首次升级会把旧 `config.json` 导入“默认方案”，且不会改写原文件。

---

### 第四步：一键挂机
1. 点击 **“🚀 开始挂机”** 按钮，软件进入自动循环挂机监控状态。
2. 自动挂机流程：
   - 当画面识别到 **“开始游戏”** 按钮时 ➔ 自动串行执行您配置的步骤（如按1点A，按2点B） ➔ 完毕后自动点击“开始游戏”启动波次。
   - 识别优先使用模板；如果鼠标位于 Roblox 外导致按钮悬停外观变化，则使用中央绿色按钮的颜色、尺寸、长宽比和位置联合识别，不需要把鼠标一直放在游戏窗口内。
   - 战斗期间可以使用其他窗口，但下一次画面检测前必须保证 Roblox 可见且未最小化。
   - 检测到下一局的“开始游戏”按钮后，重新执行动作链。
3. 如果要退出或微调，随时点击 **“🛑 停止挂机”**。

## 💡 常见问题与小提示 (Tips)
* **Q: 为什么挂机时点击不了或者反应慢？**
  * 请确认运行 `gui_app.py` 的 Python 环境是以管理员身份运行，或者没有被 Windows 的账户控制 UAC 限制。如果发现无法点击，请尝试以**管理员身份**打开命令提示符或 PowerShell，然后再启动 `gui_app.py`。
  * 查看项目目录中的 `automation.log`。每次图像轮询都会记录最高置信度、截图/匹配耗时、鼠标是否位于 Roblox 内、前台窗口句柄和目标句柄。
  * 项目目录中的 `diagnostics/` 会保存鼠标进出 Roblox、识别到下局按钮以及每隔 30 秒的关键帧。单次运行最多保存 30 张，便于对照“按钮已出现但未识别”的实际画面。
* **Q: 为什么我改变了游戏窗口大小，鼠标摆放的位置依然是对的？**
  * 这是因为本工具采用的是**相对窗口比例定位**，不论窗口大小如何变动，它都会自动换算出匹配当前窗口的分辨率坐标，极其稳健！
* **Q: 为什么选点没有保存？**
  * 如果点击位置不在所选 Roblox 的客户区内，程序会明确拒绝该坐标，不再把错误坐标静默改成窗口边缘。
